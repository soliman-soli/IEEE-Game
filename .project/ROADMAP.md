# Roadmap

| Phase | Output | Gate |
|---|---|---|
| 0 Reference study | Component inventory + pick list | User approves pick list |
| 1 Discovery | Visual → Gameplay → Track → Admin → Technical decisions | User says discovery is done |
| 2 Product definition | PRD, flows, mechanics/admin/display specs, architecture, schema, sync strategy, repo structure | User approval |
| 3 Visual design | Tokens, palette, type, components, track, vehicles, motion, screen specs | User approval |
| 4 Implementation | Engine/server → Player → Display → Admin | Per-module review |
| 5 Testing | 50+ bot load test, lifecycle and fairness cases | Pass |
| 6 Event readiness | QR flow, protected admin, fullscreen display, run-sheet, network fallback | Dry run |
